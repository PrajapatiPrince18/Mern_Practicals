## 🚀 Quick Start Instructions

### Running React Frontend Practicals (01 - 04)
Navigate into any frontend directory (`MERN_01`, `MERN_02`, `MERN_03`, or `MERN_04`) and run:
```bash
npm install
npm run dev
```

### Running Backend Express / Node Practicals (05 - 07)
Navigate into any backend directory (`MERN_05`, `MERN_06`, or `MERN_07`) and run:
```bash
npm install
node server.js
```
